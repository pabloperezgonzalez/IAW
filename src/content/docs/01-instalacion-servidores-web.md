### RA1. Prepara el entorno de desarrollo y los servidores de aplicaciones Web instalando e integrando las funcionalidades necesarias (10%).

| Criterio de evaluación | Tipo | Ponderación |
|:-----------|:-----:|:-----:|
| a) Se ha identificado el software necesario para su funcionamiento. | Teórico | 5 % |
| b) Se han identificado las diferentes tecnologías empleadas. | Teórico | 10 % |
| c) Se han instalado y configurado servidores Web y de bases de datos. | Práctico | 20 % |
| d) Se han reconocido las posibilidades de procesamiento en los entornos cliente y servidor. | Teórico | 10 % |
| e) Se han añadido y configurado los componentes y módulos necesarios para el procesamiento de código en el servidor. | Práctico | 15 % |
| f) Se ha instalado y configurado el acceso a bases de datos. | Práctico | 15 % |
| g) Se ha establecido y verificado la seguridad en los accesos al servidor. | Práctico | 15 % |
| h) Se han utilizado plataformas integradas orientadas a la prueba y desarrollo de aplicaciones Web. | Práctico | 5 % |
| i) Se han documentado los procedimientos realizados. | Práctico | 5 % |
