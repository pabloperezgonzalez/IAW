### RA2. Implanta gestores de contenidos seleccionándolos y estableciendo la configuración de sus parámetros.

| Criterio de evaluación | Tipo | Ponderación |
|:-----------|:-----:|:-----:|
| e) Se han personalizado y configurado los gestores de contenidos. | Práctico | 15 % |

### 1. Introducción
Una vez instalado un gestor de contenidos, es necesario **configurarlo y personalizarlo** para adaptarlo a las necesidades del sitio Web. La configuración permite modificar aspectos relacionados con:

- Información general del sitio.
- Usuarios y permisos.
- Apariencia.
- Idioma.
- Menús.
- Contenidos.
- Extensiones.
- Configuración del servidor.
- Opciones de funcionamiento.

El objetivo es transformar una instalación básica en un **sitio Web adaptado a las necesidades del proyecto**.

### 2. Configuración general
Lo primero que debemos configurar son los parámetros generales del CMS, que permiten adaptar su comportamiento básico. Entre ellos podemos encontrar:

- Nombre del sitio Web.
- Descripción.
- URL del sitio.
- Idioma.
- Zona horaria.
- Formato de fecha y hora.
- Correo electrónico del administrador.
- Página principal.

> Por ejemplo: **CMS → Configuración general → Nombre + URL + idioma + zona horaria**

### 3. Usuarios, roles y permisos
Los CMS permiten crear diferentes usuarios con distintos niveles de acceso. Por ejemplo:

| Rol | Funciones |
|---|---|
| Administrador | Control total del CMS |
| Editor | Gestiona y publica contenidos |
| Autor | Crea y gestiona sus propios contenidos |
| Colaborador | Puede crear contenidos con restricciones |
| Usuario registrado | Acceso a determinadas funciones |

> La utilización de diferentes roles permite aplicar el principio de **mínimo privilegio**. Cada usuario debe disponer únicamente de los permisos necesarios para realizar sus funciones.

### 4. Personalización de la apariencia
Una de las características más visibles de un CMS es la posibilidad de modificar su apariencia. La personalización debe mantener una apariencia coherente y facilitar la navegación. Podemos configurar:

- Temas.
- Plantillas.
- Logotipo.
- Colores.
- Tipografías.
- Cabecera.
- Pie de página.
- Menús.
- Imágenes.

> Por ejemplo: **Tema → Logotipo → Colores → Menú → Página principal**

### 5. Organización de los contenidos
Los CMS permiten organizar la información para facilitar su gestión y navegación. Podemos utilizar:

- Páginas.
- Entradas o artículos.
- Categorías.
- Etiquetas.
- Menús.
- Secciones.

> Por ejemplo, una Web corporativa podría organizarse como: **Inicio → Empresa → Servicios → Noticias → Contacto**

### 6. Configuración de extensiones
Los CMS pueden ampliar sus funcionalidades mediante:

- Plugins.
- Módulos.
- Componentes.
- Extensiones.
- Widgets.

Por ejemplo, podemos instalar una extensión para:

- Crear formularios.
- Mejorar el SEO.
- Realizar copias de seguridad.
- Gestionar una tienda online.
- Mejorar la seguridad.
- Generar estadísticas.

> Sin embargo, debemos instalar únicamente las extensiones necesarias. Cada extensión adicional puede aumentar la complejidad y la superficie de ataque del sistema.

### 7. Configuración de funcionalidades
Además de la apariencia, podemos configurar el comportamiento del CMS. Por ejemplo:

- Comentarios.
- Registro de usuarios.
- Publicación de contenidos.
- Notificaciones.
- Gestión de archivos.
- Tamaño máximo de subida.
- Formatos permitidos.
- Motor de búsqueda.
- Permisos de acceso.

> La configuración debe realizarse teniendo en cuenta los requisitos del sitio Web.

### 8. Configuración según el tipo de CMS
La personalización dependerá del tipo de gestor utilizado.

| CMS | Ejemplos de configuración |
|---|---|
| WordPress | Temas, plugins, menús, usuarios |
| Joomla | Plantillas, módulos, componentes, usuarios |
| Drupal | Temas, módulos, tipos de contenido, permisos |
| PrestaShop | Productos, categorías, pagos, envíos |
| Moodle | Cursos, usuarios, roles, actividades |

> Aunque cada CMS dispone de su propia interfaz, los conceptos de **configuración, personalización, usuarios y extensiones** son comunes.

### 9. Comprobación de la configuración
Después de realizar cambios debemos comprobar que funcionan correctamente. Debemos verificar:

- La página principal.
- Los menús.
- Los contenidos.
- Los usuarios y permisos.
- Las extensiones instaladas.
- La apariencia.
- Los formularios.
- La navegación.
- El acceso desde diferentes usuarios.

> El proceso puede resumirse como: **Configurar → Personalizar → Guardar → Probar → Corregir**

### 10. Actividad UP2.5. Personalización y configuración de los gestores de contenidos - CE2.e)
Sobre la instalación de **WordPress realizada en la actividad anterior con XAMPP**, personaliza el sitio Web y configura sus principales parámetros para adaptarlo a una temática concreta.

a. Configurar el nombre, descripción, idioma y zona horaria del sitio.

b. Seleccionar e instalar un tema adecuado para la temática elegida.

c. Personalizar la apariencia general del sitio.

d. Configurar el logotipo, título, colores y otros elementos visuales.

e. Crear varias páginas estáticas.

f. Crear diferentes entradas o publicaciones.

g. Organizar las entradas mediante categorías y etiquetas.

h. Crear y configurar un menú de navegación.

i. Crear diferentes usuarios con distintos roles y permisos.

j. Configurar las opciones generales de comentarios, imágenes y lectura del sitio.

k. Instalar y configurar una extensión que aporte una funcionalidad adicional.

l. Comprobar que todos los cambios se muestran correctamente en la parte pública del sitio.

### Resultado esperado
Disponer de un sitio WordPress personalizado y correctamente configurado, con una apariencia coherente, contenidos organizados, menú de navegación, usuarios con diferentes permisos y funcionalidades adicionales.
