### CE1.a) Factores que impulsan la continua expansión y evolución de las redes de datos

**¿Por qué comenzar aquí?**

Antes de estudiar qué es una red, conviene comprender por qué existen y por qué evolucionan constantemente. Este criterio sirve como introducción motivadora al módulo profesional de Planificación y Administración de Redes y permite contextualizar la importancia de las redes en la sociedad actual.

Algunos aspectos que se tratarán son:

- Digitalización de empresas y administraciones.
- Crecimiento de Internet.
- Computación en la nube.
- Internet de las Cosas (IoT).
- Movilidad.
- Teletrabajo.
- Streaming y servicios digitales.
- Inteligencia Artificial.
- Ciberseguridad.

### CE1.c) Tipos de red y topologías

Una vez entendida la necesidad de las redes, el siguiente paso es responder a la pregunta:

> ¿Cómo pueden organizarse las redes?

Aquí se presentan conceptos fundamentales:

- LAN: Local Area Network (Red de área local).
- MAN: Metropolitan Area Network (Red de área metropolitana).
- WAN: Wide Area Network (Red de área amplia).
- PAN: Personal Area Network (Red de área personal).
- SAN: Storage Area Network (Red de área de almacenamiento).
- VPN: Virtual Private Network (Red virtual privada).

Además, de introducir las distintas topologías de red:
- Bus.
- Anillo.
- Estrella.
- Árbol.
- Malla.
- Híbridas.

### CE1.g) Elementos funcionales, físicos y lógicos de una red

Después de conocer cómo son las redes, resulta natural estudiar de qué están formadas. Aquí se presentan los siguientes conceptos, de manera general:

- Hosts.
- Clientes.
- Servidores.
- Interfaces de red.
- Tarjetas NIC.
- Direcciones MAC.
- Direcciones IP.
- Segmentos.
- Dominios de colisión.
- Recursos compartidos.
- Servicios de red.

### CE1.b) Medios de transmisión

Cuando ya conocemos los elementos de una red, surge una nueva pregunta:

> ¿Cómo se conectan físicamente esos dispositivos?

Para entender cómo viaja realmente la información, se introducirá:

- Cable de par trenzado.
- Cable coaxial.
- Fibra óptica.
- Medios inalámbricos.
- Características.
- Ventajas.
- Inconvenientes.
- Ancho de banda.
- Atenuación.
- Interferencias.

### CE1.d) Arquitecturas de red y niveles

Hasta este momento, todo lo estudiado pertenece principalmente al mundo físico. Ahora se introduce una idea mucho más abstracta:

> ¿Cómo consiguen comunicarse equipos completamente distintos?

Es el momento ideal para introducir:

- Arquitectura en capas.
- Modelo OSI.
- Modelo TCP/IP.
- Función de cada capa.

Este criterio sirve de puente hacia el funcionamiento interno de las comunicaciones.

### CE1.e) Concepto de protocolo de comunicación

Una vez conocidas las capas, aparece una cuestión lógica:

> ¿Qué reglas siguen los dispositivos para comunicarse?

Aquí se introduce el concepto de protocolo y se explicarán los protocolos más conocidos:

- HTTP.
- HTTPS.
- FTP.
- DNS.
- DHCP.
- TCP.
- UDP.
- IP.
- ICMP.

### CE1.f) Funcionamiento de las pilas de protocolos

Después de conocer las capas y los protocolos por separado, llega el momento de unir ambos conceptos, explicando cómo viaja un dato desde una aplicación hasta el medio físico. Aquí se introducen los conceptos de:

- Encapsulación.
- Desencapsulación.
- PDU.
- Flujo de datos entre capas.
- Relación entre protocolos.

### CE1.h) Dispositivos de interconexión

Finalmente, se estudian los dispositivos reales que implementan todo lo aprendido en este RA. Ahora tiene sentido hablar de:

- Repetidores.
- Hubs.
- Bridges.
- Switches.
- Routers.
- Gateways.
- Puntos de acceso.
- Firewalls.
