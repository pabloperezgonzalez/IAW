### RA6. Genera documentos Web con acceso a bases de datos utilizando lenguajes de guiones de servidor (20 %).

| Criterio de evaluación | Tipo | Ponderación |
|:-----------|:-----:|:-----:|
| a) Se han identificado los sistemas gestores de bases de datos más utilizados en entornos Web. | Teórico | 10% |
| b) Se ha verificado la integración de los sistemas gestores de bases de datos con el lenguaje de guiones de servidor. | Práctico | 10% |
| c) Se ha configurado en el lenguaje de guiones la conexión para el acceso al sistema gestor de base de datos. | Práctico | 15% |
| d) Se han creado bases de datos y tablas en el gestor utilizando el lenguaje de guiones. | Práctico | 15% |
| f) Se han aplicado criterios de seguridad en el acceso de los usuarios. | Práctico | 15% |
| e) Se ha obtenido y actualizado la información almacenada en bases de datos. | Práctico | 25% |
| g) Se ha verificado el funcionamiento y el rendimiento del sistema. | Práctico | 10% |
